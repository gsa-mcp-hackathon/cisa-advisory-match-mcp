# Manufacturer alias expansion research

Reviewed November 6, 2026. Requested by Johnson Chen for GSA MCP Hackathon. This is a proposed catalog patch, not a runtime release. Only exact documented names are enumerated. Sources containing legal text are used solely to establish company naming, not to give legal advice.

Original CISA CSAF snapshot commit: `020f7c01c13b08df34a9557e734d76ed7943c537`. CISA source branches and document titles were inspected from the downloaded pinned public snapshot. Manufacturer pages were retrieved through web search; sources below are public primary sources.

Patch: 58 records (3 existing-record updates; 55 new records).

Each group lists the precise proposed names and why the mode was selected. The runtime still requires a product/version rule; manufacturer identity alone does not establish vulnerability. Blank or unsourced spelling alternatives were not generated.
