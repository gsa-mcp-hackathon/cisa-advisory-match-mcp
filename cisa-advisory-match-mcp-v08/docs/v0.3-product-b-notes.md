## Deliberately excluded

- Generic names such as PLC, HMI, PIMS, EMS, OPC Server, Control Builder and unqualified CODESYS do not identify a unique product.
- ABB System 800xA Base and the broad System 800xA are not equivalent.
- GT Works3, GT Designer3 and GT SoftGOT2000 are not equivalent even when shipped together.
- The current Control Win SL name is not used to rewrite older Control Win V3 or component-qualified CSAF labels.
- WebAccess/SCADA, /CNC, /NMS and /DMP are kept distinct. Bare WebAccess needs further historical review.
- No invented human misspellings were added. Case and whitespace are already normalized by the engine.
- Some well-defined names may not intersect the pinned corpus; completeness and successful version matching are separate measures.

## Direct corpus intersection

A case-insensitive exact vendor/product comparison found 23 of 40 proposed groups intersecting 35 scoped product labels in the pinned OT/white snapshot. This is a narrow naming-coverage check, not a runtime matching or accuracy test. Remaining documented groups are prospective vocabulary, not credited as existing corpus coverage.

## Source checks

- Manufacturer documentation directly defines TwinCAT 3 XAE and XAR separately, including the expanded names.
- Each added Mitsubishi Electric-prefixed spelling was asserted against an actual product_name branch in CISA ICSA-20-212-04 at commit 020f7c01c13b08df34a9557e734d76ed7943c537. No name was generated from a blanket prefix rule.
- Many Mitsubishi version strings contain letters, so successful name identity can still produce needs_review under the existing numeric-version grammar.
- Original CISA records for Yokogawa PRM and Hitachi MSM were suggested to the independent reviewer for real-source tests.
