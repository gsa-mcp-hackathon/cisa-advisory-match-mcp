# Long-tail product mapping research

Prepared for GSA MCP Hackathon at Johnson Chen's request, November 6, 2026.

This contribution contains 31 new groups: 28 equivalent and 3 review-only candidates, with 91 distinct case-insensitive product labels. It does not modify the main catalog. Product names alone do not establish affected versions.

## Source method

Public manufacturer documentation was searched and read through web retrieval. The CISA product-tree labels were inspected in the complete local source snapshot pinned to commit `020f7c01c13b08df34a9557e734d76ed7943c537`. Every CISA URL in this contribution uses that commit. The source URL/title and rationale for every group are retained in `product-c.json`. Counts include both ordinary and alternative names, not 91 additional alternatives.

## Important boundaries

- Eaton IPM, IPM Virtual Appliance and IPM Infrastructure have distinct groups. A parenthetical acronym in the original CISA product label supplies a documented name expansion; it does not permit stripping arbitrary parentheses elsewhere. Explicit IPM v1 remains distinct.
- SEL RTAC software is not equated to controller hardware. QuickSet Device Manager, Template and Designer, Team services, and Architect ICD packages are not assigned to their parent application automatically.
- Triangle DTM is manufacturer-scoped and never means Delta DTM Soft or a generic device type manager.
- Horner EnvisionRV and Cscape remain distinct; the new spelling group includes only EnvisionRV forms used in manufacturer documentation.
- Delta DTMSoft/DTM Soft is an explicitly documented spelling variation. DTN Soft, DIAViewX, DIAScreen and ScreenEditor remain distinct from the near-named entries.
- WellinTech KingView, KingSCADA, KingHistorian and KingView HistoryServer remain distinct.
- Ecava editions and runtime/development components remain separate.
- FATEK Automation FV Designer to FvDesigner remains a candidate because release-line identity was not established. WinProladder for DOS is excluded.
- WECON LeviStudioU is only mapped to the company-prefixed source label. LeviStudio, LEVI Studio HMI Editor and PI Studio are not merged. One CISA PI Studio advisory contains two different named entries with different version cutoffs, so co-occurrence was not accepted as equivalence.
- Moxa MXview and MXview One are separately documented products; the replacement relationship is candidate-only. MXview ToGo and MXview One Central Manager are excluded.
- Phoenix Contact PC Worx Engineer to PLCnext Engineer is candidate-only due to the renamed release line. PC Worx and PC Worx Express are excluded.

## Useful regression cases

- `Eaton / IPP` can name-match CISA `Eaton Intelligent Power Protector (IPP)`; `IPM` cannot match the Virtual Appliance or Infrastructure label.
- `Schweitzer Engineering Laboratories / QuickSet` can name-match the CISA prefixed acSELerator label, but `RTAC` cannot match acSELerator RTAC software.
- `Horner Automation / Cscape EnvisionRV` and the spaced Envision RV source name can match; plain `Cscape` cannot.
- `Delta Electronics / DTMSoft` can match `DTM Soft`; `DTN Soft` cannot.
- `Moxa / MXview` versus `MXview One` requires review; the same names must not become direct equivalent mappings via group overlap.
- `FATEK Automation / FvDesigner` versus `Automation FV Designer` requires review, and neither maps to PM Designer.

Several extra software groups, including some SEL tools, ProSoft utilities and Triangle testing tools, have primary-source naming documentation but may not appear in this CISA snapshot. The coverage audit should identify that distinction rather than imply all added labels improve advisory coverage immediately.

## Observed local checks

The v0.2 baseline plus only these 31 proposed groups passed 324 directional mapping and scoped negative boundary checks using the existing AliasCatalog engine. These checks establish catalog/engine consistency, not general matching accuracy or completion of IBM agent tests.
