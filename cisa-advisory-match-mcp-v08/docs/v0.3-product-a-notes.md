# Product expansion A source notes

Prepared for GSA MCP Hackathon. Research checked November 6, 2026.

43 upsert records: 2 existing groups expanded; all other IDs are new.

The JSON is research input for integration and review, not a standalone claim of runtime acceptance. Each record carries official source URLs. Where applicable, a frozen CISA CSAF file from commit 020f7c01c13b08df34a9557e734d76ed7943c537 corroborates the original product label. Name presence in one document never establishes equivalence to another named product.

## Important exclusions

- FTAC is not included: Rockwell uses it for an AssetCentre course label, while its Historian SE Installation Assistant explicitly expands it as FactoryTalk Administration Console. A single acronym cannot establish identity.
- SINEC NMS was not given a bare Network Management System alias. That phrase describes a category and other Siemens network-management products exist.
- WinCC Runtime Advanced and Professional stay separate. S7-PLCSIM and S7-PLCSIM Advanced stay separate.
- IGSS Definition (Def.exe), PI AF Server/SDK, and AVEVA Application Server IDE remain component identities.
- No historical name change is accepted as an automatic affected-version match.
- Ten Siemens part-number records preserve the complete SKU. Neither the generic family nor an abbreviated model is equivalent to a regional SKU.
- Manufacturer names such as AVEVA Software, LLC and Schneider Electric Software, LLC are a separate review task. These product mappings do not imply corporate/subsidiary equivalence.

## Integration review corrections

The integrated catalog keeps SIMATIC PDM and Process Device Manager equivalent but treats bare PDM as a review-only candidate, since Siemens also uses PDM for Product Data Management: https://www.siemens.com/en-gb/technology/product-data-management-pdm/.
